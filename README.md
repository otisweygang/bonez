# bONEZ bIZARRE

Static portfolio site for the artist bONEZ bIZARRE.

No build step, one stylesheet, two JS files.

## Run locally

Paths are root absolute (`/assets/...`) hence the site must be served

```
python3 -m http.server 8000
```

Then visit http://localhost:8000 (VS Code's Live Server extension works too)
